# LON 龙系长线策略 —— 15 分钟多空双向回测

## 策略与执行

信号（指标反向对称）：
- LON 0 轴**下方**柱体连续两天变短 -> **做多**（空头能量衰竭）
- LON 0 轴**上方**柱体连续两天变短 -> **做空**（多头能量衰竭）

两种执行对比：**纯做多**（卖出信号清仓）vs **多空双向**（卖出信号反手做空）。

周期 15 分钟（约 60 天），手续费万分之三，收益率法回测。数据：Yahoo Finance。

## 结论与分析

**总体：多空双向 −2.3% < 纯做多 +0.9% < 买入持有 +2.6%（17 品种均值）。**
"加上做空"并不是无脑改进——它的效果完全取决于标的的趋势方向，是一把双刃剑。

**1. 加密货币是多空策略的最佳拍档（平均 +10.6%，夏普 0.59，4/4 正收益）。**
| 品种 | 买入持有 | 纯做多 | 多空双向 |
| --- | ---: | ---: | ---: |
| BTC | −17.8% | −7.3% | **+3.0%** |
| ETH | −27.1% | −9.5% | **+7.9%** |
| SOL | −15.5% | +0.7% | **+14.8%** |
| DOGE | −14.0% | +2.3% | **+16.9%** |
近 60 天加密货币整体下跌，做空腿赚到了下跌的钱，4 个币种多空双向**全部正收益、全部大幅跑赢买入持有**。
加密货币 24 小时交易、双向波动、均值回归性强，与 LON 的"顶部/底部反转"信号高度契合。

**2. 上涨趋势品种上，做空腿是负贡献（美股 −4.2%、指数 −6.1%、夏普低至 −1.56）。**
标普 +3.6%→−8.1%、纳斯达克 +6.5%→−9.8%、铜 +(−1.6%)→−10.7%：在单边上涨行情里，
LON 的"顶部反转"信号往往来得太早，做空被上涨趋势反复打脸，把原本纯做多的正收益拖成负的。

**3. 黄金、天然气等近期回落/震荡品种，做空腿小幅加分。**
黄金 GC −3.6%→**+5.7%**（夏普 0.69）、天然气 +12.9%→+4.5% 仍为正。趋势向下时做空有效。

**4. 规律总结：做空腿的盈亏 ≈ 标的趋势方向。**
- 下跌 / 震荡品种（加密货币、近期黄金）→ 做空赚钱，多空双向显著优于纯做多。
- 上涨 / 强趋势品种（美股、股指、铜）→ 做空亏钱，应当只做多。
- 17 个品种里多空优于纯做多的有 5 个，**几乎全部是同期下跌的品种**。

**5. 实用建议。**
- **不要全市场无差别开做空**，应加"趋势/状态过滤"决定是否启用做空腿：
  例如仅当标的处于下跌趋势（价格位于长期均线下方，或 LON 长期为负）时才允许做空，
  上涨趋势只做多。这样可保留纯做多在牛市的收益，同时拿到熊市做空的超额。
- **若专做加密货币**，当前这套对称多空（底部做多 / 顶部做空）就已经是很好的配置。
