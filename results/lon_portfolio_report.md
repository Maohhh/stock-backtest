# LON 组合策略回测（多品种 + 排序选股 + 资金使用率上限）

## 规则

| 方向 | 入场 | 退出 | 排序 |
| --- | --- | --- | --- |
| 做多 | LON < 0 且 MA5 > MA10 > MA20 | LON > 0 且 LON 连续 2 日下降 | (LON−LONMA) 降序 |
| 做空 | LON > 0 且 MA5 < MA10 < MA20 | LON < 0 且 LON 连续 2 日上升 | (LONMA−LON) 降序 |

组合设置：本金 **10 万**；每仓位 **10%** 权益；总敞口(多+空)上限 **70%**（最多 7 个并发仓位，
资金不够时按排序取前几名）；真·日线（按自然日合成 15min 数据，2023-09~2026-05，约 2.7 年）；
手续费万分之三。关键改进：用 **MA5>MA10>MA20 多头排列** 作为顺势过滤，让 LON 信号顺势而非逆势。

组合分散 + 70% 限仓把单品种 −40%~−90% 的极端回撤压到了 −9%。

## 解读

1. **加 MA 顺势过滤 + 组合化是这套 LON 信号第一次"能看"**：之前单品种逆势抓反转动辄 −50%，
   现在全市场组合年化 +4%、回撤 −9%、盈亏比 1.62，风险收益结构健康。
2. **最佳板块：能源化工(品种多、分散好，+2.5%)、其他(集运等趋势品种，盈亏比 1.90)**。
   能源化工 22 个品种摊开后是最稳的主力贡献板块。
3. **股指胜率高达 72% 但盈亏比仅 0.53**：典型"赢多次小钱、偶尔亏大钱"，靠胜率撑住微利。
4. **拖累板块：贵金属(AU/AG 仅 2 个、趋势极强、−4.1%)、有色、国债**。贵金属样本太少且单边性强，
   不适合并入；国债低波动被手续费磨损(盈亏比 0.20)。
5. **注意**：本表为**样本内**结果；此前对趋势版的样本外检验显示 edge 会缩水，
   实盘应按"剔除贵金属/国债、以能源化工+其他+油脂农副为主"的思路，并做样本外/滚动验证。

> 结论：以"LON<0 + 均线多头排列"入场、"LON 翻正且连续 2 日回落"离场、(LON−LONMA) 排序选仓、
> 单仓 10%/总仓 70% 的**分散组合**，把 LON 做成了一个**年化 +4%、回撤 −9%、盈亏比 1.62、夏普 0.53**
> 的低频组合策略——是目前最值得继续打磨的形态。重点配置能源化工/其他/油脂农副，回避贵金属/国债。
