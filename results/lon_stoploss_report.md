# LON 止损止盈状态机版 —— 期货 15 分钟回测

## 规则（仅用 LON 指标）

- **开多**：LON 0 轴下方(绿柱)，柱体长度连续两根变短。
- **开空**：LON 0 轴上方(红柱)，柱体长度连续两根变短。
- **止损**：持多且仍在 0 轴下方时绿柱变长 1 根 / 持空且仍在 0 轴上方时红柱变长 1 根 → 平仓。
- **止盈**：多单反转到 0 轴上方、红柱开始变短 / 空单反转到 0 轴下方、绿柱开始变短 → 平仓。

实现为状态机（多/空/空仓三态），大部分时间空仓，已验证与逐 bar 判定一致。
数据：仓库 `data_futures/15min/`（75 品种，2023-09~2026-05）。手续费万分之三。

## 结论：规则能抓到波段，但被手续费打死（实盘最差）

**全市场 75 品种均值：本版 −52.0%，0/75 正收益。** 三版对比：

| 版本 | 全市场均收益 | 正收益数 |
| --- | ---: | ---: |
| 旧·纯做多（始终在场，卖出清仓） | −10.2% | 17/75 |
| 旧·多空双向（始终反手） | −25.6% | 13/75 |
| **新·止损止盈状态机** | **−52.0%** | **0/75** |

### 根因：1 根变长就止损 → 在 15 分钟噪声里被反复扫损，换手爆炸

本版每个品种 **600~1500 笔交易**（旧版仅 250~400），一根 K 线约每 15 根就进出一次。
万分之三手续费按换手累计，**单品种成本拖累高达 60%~82%**。去掉手续费后真相浮现：

| 品种 | 有手续费(万3) | 零手续费 |
| --- | ---: | ---: |
| 菜油 OI | −15.3% | **+57.7%** |
| 菜粕 RM | −29.2% | **+32.3%** |
| 20号胶 NR | −32.3% | **+28.4%** |
| 玉米淀粉 CS | −51.2% | −11.1% |
| 白糖 SR | −48.1% | −4.7% |
| **全市场均值** | **−52.0%** | **−15.4%（16/75 正）** |

- **逻辑本身没错**：零手续费下，菜油/菜粕/橡胶等"中等波动+宽幅震荡"品种能抓到 +30%~+58%，
  说明"两根变短进场、反向见顶止盈"确实捕捉到了波段。
- **但 1 根变长的止损太紧**：15 分钟绿/红柱极少单调收缩，进场后常被下一根反向 K 线立刻扫损，
  再触发再进场……换手率被推到极高，万3 手续费就把全部收益吃光，净值反而比旧版差得多。
- **淀粉、白糖即便零手续费仍亏**（−11%、−5%）：波动太低(10%)，每个波段振幅本就盖不住成本，
  与之前结论一致——低波品种不适合该策略。

## 改进方向

1. **放宽止损**：从"1 根变长"改为"连续 2 根变长"或价格/ATR 止损，大幅降低换手。
2. **降频**：上更高周期（60 分钟/日线），或要求进场需 3+ 根连续变短，减少假信号。
3. **先筛品种**：只做中等波动(年化~15-30%)、宽幅震荡品种（菜油/菜粕/橡胶/纸浆等），
   剔除低波(淀粉/白糖/玉米)与高波(双焦/硅锂/航运)。

> 一句话：止损止盈的想法在零成本下能赚钱，但"1 根就止损"在 15 分钟上换手太高，
> 万3 手续费令其成为三版中实盘最差的一版。要可用必须先**放宽止损 + 降频 + 筛品种**。

## 补充实验：放宽止损 + 升周期（应用户建议）

### 1) 放宽止损（15 分钟，万3）——只能小修，仍亏

| 止损宽度 | 全市场均收益 | 正收益 | 平均交易 |
| --- | ---: | ---: | ---: |
| 1 根变长（原版） | −52.0% | 0/75 | 940 |
| 连续 2 根变长 | −44.8% | 1/75 | 767 |
| 连续 3 根变长 | −41.0% | 2/75 | 676 |

放宽到 3 根，换手仍有 ~680 笔/品种，万3 手续费照样吃掉收益，仍是 −41%。
止盈与再进场本身就高频，光放宽止损不解决问题。

### 2) 升周期才是关键（万3）

把 15 分钟按 N 根合成更高周期（4 根≈60min，16 根≈日线）：

| 周期 | stop=1 | stop=2 | 平均交易 |
| --- | ---: | ---: | ---: |
| 15min | −52.0% (0/75) | −44.8% (1/75) | ~940 |
| 60min | −18.5% (12/75) | −15.1% (16/75) | ~220 |
| **日线** | −1.9% (28/75) | **+0.8% (31/75)** | **~50** |

交易数从 ~940 降到 ~50，手续费不再主导，日线均值终于回到 0 附近。

### 3) 致命问题：有效品种随周期完全反转 —— 没有稳定优势

| | 15 分钟（零成本最佳） | 日线（stop2） |
| --- | --- | --- |
| 菜油 OI | +58% ✅ | **−11%** ❌ |
| 菜粕 RM | +32% ✅ | **−19%** ❌ |
| 橡胶 RU | +28% ✅ | **−45%** ❌ |
| 集运欧线 EC | −80% ❌ | **+389%** ✅ |
| 纯碱 SA / 烧碱 SH | 亏 | +64% / +62% ✅ |

- **波动率规律也反转**：15 分钟「中波好、高波灾难」；日线「高波(>30%)最好 +22%、中波 −5%」。
- 日线 +0.8% 的均值由极少数高波趋势品种(集运欧线 +389% 等)拉动，**31/75 正收益、中位数仍为负**。

**结论**：放宽止损只能小幅止血；升到日线能把手续费问题解决、均值回到 0 附近，但
**同一套规则在不同周期上的"有效品种"完全对调、波动率规律反向**，说明 LON 反转策略
**没有稳定、可迁移的优势**——正收益主要来自个别品种/特定区间的运气，而非结构性 edge。
若要实盘，必须接受"它只是个需要严格品种+周期择时的弱信号"，不能指望普适。
