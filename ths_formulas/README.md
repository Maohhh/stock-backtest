# 同花顺期货公式：双均线 + MACD 0轴择时

以 **MA10、MA20** 两条均线的金叉死叉择时，用 **MACD 的 0轴**（DIFF/DEA 围绕的零轴）判断趋势方向：

- MACD **0轴上方**（DIF>0）+ MA10 **金叉** MA20 → **做多**
- MACD **0轴下方**（DIF<0）+ MA10 **死叉** MA20 → **做空**

即「**MACD 0轴定方向（顺势） + 双均线交叉定时机（择时）**」。

## 0轴是怎么来的

价格均线 MA10/MA20 在几千点上下，本身没有0轴。这里的 0轴来自 **MACD**：

```
DIF = EMA(CLOSE,12) - EMA(CLOSE,26)
DEA = EMA(DIF,9)
MACD = (DIF - DEA) * 2
```

DIF/DEA 围绕 **0 轴**波动：DIF>0 表示中短期趋势向上（0轴上方），DIF<0 表示向下（0轴下方）。
只在 0轴上方接受金叉做多、只在 0轴下方接受死叉做空，过滤掉逆势交叉。

## 文件说明

| 文件 | 类型 | 用途 |
|------|------|------|
| `双均线0轴期货指标.txt` | 主图叠加 | 在K线上画 MA10/MA20，标注「做多/做空」信号 |
| `MACD0轴信号副图.txt` | 副图 | 显示 MACD/DIFF/DEA/0轴，核对信号位置 |
| `双均线0轴交易系统.txt` | 交易系统(TS) | 输出 ENTERLONG/ENTERSHORT，可回测/预警 |

## 导入方法（同花顺）

1. 公式管理器（`Ctrl+F` 或 工具→公式管理器）。
2. **主图指标**：技术指标 → 新建 → 选「主图叠加」，粘贴 `双均线0轴期货指标.txt`，保存。
3. **副图指标**：技术指标 → 新建 → 选「副图」，粘贴 `MACD0轴信号副图.txt`，保存。
4. **交易系统**：交易系统 → 新建，粘贴 `双均线0轴交易系统.txt`，保存后即可在期货品种上回测。

## 可调参数

- `N1` 快线 MA（默认 10）、`N2` 慢线 MA（默认 20）
- `SHORT/LONG/MID` MACD 参数（默认 12/26/9）

## 说明与可选调整

- **方向口径**：默认用 `DIF>0` 判断 0轴上方。若想更严格，可改为 `DIF>0 AND DEA>0`
  （DIFF、DEA 都在0轴上方）；想更激进可改为 `DIF>DEA`。需要的话我帮你改。
- 交易系统默认「反向交叉即平仓」（死叉平多、金叉平空），可按需改为固定止损/止盈。
- 信号在 K 线**收盘确认**后产生，避免盘中反复跳动。
