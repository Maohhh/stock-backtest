# 同花顺期货公式：双均线 + 0轴金叉死叉

以 **MA10、MA20** 两条线为核心，结合 **0轴** 过滤多空：

- **0轴上方** MA10 **金叉** MA20 → **做多**
- **0轴下方** MA10 **死叉** MA20 → **做空**

## 为什么要有"0轴"

价格均线（如收盘价的 MA10/MA20）数值在几千点上下，**永远不会穿过 0**，
所以"0轴上/下方"对价格均线没有意义。

本公式先把价格转换为**相对长期基准（MA60）的偏离百分比**：

```
偏离 = (CLOSE - MA(CLOSE,60)) / MA(CLOSE,60) * 100
```

该序列天然围绕 **0 轴**上下波动（>0 表示价格在中长期均线上方，<0 表示下方）。
再对"偏离"取 MA10、MA20，得到两条围绕 0 轴的均线。这样：

- 金叉/死叉 → 短期动能转向
- 0轴上/下方 → 中长期趋势方向（顺势过滤）

二者结合 = **顺势 + 择时**，避免在中长期下跌趋势中盲目做多（反之亦然）。

## 文件说明

| 文件 | 用途 |
|------|------|
| `双均线0轴期货指标.txt` | 副图指标，画两线+0轴，标注"做多/做空"信号 |
| `双均线0轴交易系统.txt` | 交易系统(TS)，输出 ENTERLONG/ENTERSHORT，可回测 |

## 导入方法（同花顺）

1. 打开同花顺 → 公式管理器（快捷键 `Ctrl+F` 或 工具→公式管理器）。
2. **指标**：技术指标 → 新建 → 选择"副图"，粘贴 `双均线0轴期货指标.txt` 内容，保存。
3. **交易系统**：交易系统 → 新建，粘贴 `双均线0轴交易系统.txt` 内容，保存后即可在期货品种上做交易系统回测。
4. 将指标加载到期货 K 线副图查看；或在交易系统中运行回测/预警。

## 可调参数

在指标设置中可调整：

- `N1` 快线周期（默认 10）
- `N2` 慢线周期（默认 20）
- `BASE` 0轴基准周期（默认 60，越大越偏长线、信号越少）

## 注意

- 偏离百分比对不同品种的波动率敏感，建议按品种/周期回测后再调 `BASE`。
- 交易系统默认"反向信号即平仓"（死叉平多、金叉平空），可按需改为定止损/止盈。
- 信号在 K 线**收盘确认**后产生，避免盘中反复触发；如需盘中信号可自行去掉收盘约束。
