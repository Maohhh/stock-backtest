{====================================================================
  名称: 双均线+MACD0轴 期货交易系统 (可回测/预警)
  平台: 同花顺 (THS) - 期货 - 交易系统(TS)
  说明: 与"双均线0轴期货指标"同源, 输出 ENTERLONG/ENTERSHORT
        等交易系统关键字, 可直接用于同花顺期货交易系统回测。

  开平逻辑:
    方向: MACD 的 0轴 (DIFF 围绕的零轴)
    择时: MA10 / MA20 金叉死叉
    开多: 0轴上方(DIF>0) MA10 金叉 MA20
    开空: 0轴下方(DIF<0) MA10 死叉 MA20
    平多: 死叉
    平空: 金叉
====================================================================}

N1:=10;
N2:=20;
SHORT:=12;
LONG:=26;
MID:=9;

MA10:=MA(CLOSE,N1);
MA20:=MA(CLOSE,N2);

DIF:=EMA(CLOSE,SHORT)-EMA(CLOSE,LONG);
DEA:=EMA(DIF,MID);

金叉:=CROSS(MA10,MA20);
死叉:=CROSS(MA20,MA10);

{ ---- 交易系统信号 ---- }
ENTERLONG:金叉 AND DIF>0;    { 0轴上方金叉 -> 开多 }
EXITLONG:死叉;               { 死叉 -> 平多 }

ENTERSHORT:死叉 AND DIF<0;   { 0轴下方死叉 -> 开空 }
EXITSHORT:金叉;              { 金叉 -> 平空 }
